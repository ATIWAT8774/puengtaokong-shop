ไฟล์หน้าร้าน:
- index.html
- app.js
- styles.css

ไฟล์หลังบ้าน (แยกจากหน้าร้าน):
- admin.html
- admin.js
- admin.css

หากต้องการเข้าหลังบ้าน ให้พิมพ์ชื่อไฟล์ admin.html เองใน URL/เปิดไฟล์โดยตรง

หมายเหตุสำคัญ:
เวอร์ชันนี้เป็น Static Website และยังเก็บคำสั่งซื้อใน localStorage ของเบราว์เซอร์
ดังนั้นระบบหลังบ้านจะเห็นเฉพาะข้อมูลที่อยู่ใน storage ของ origin/เบราว์เซอร์เดียวกัน
การเปิดขายจริงให้ลูกค้าหลายเครื่องต้องเชื่อมฐานข้อมูลกลาง เช่น Google Sheets + Google Apps Script หรือฐานข้อมูลออนไลน์
